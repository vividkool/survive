# survive (AIサバイバル・タクティクス)

## 🛠️ 開発ツール
### WebP画像加工＆透過スタジオ (Web UI)
ブラウザから画像のアップロード、透過指定（AI自動/スポイト色抜き/ブラシ消しゴム）、解像度リサイズ、WebP変換を一括で行えるローカルWebツールです。

**起動方法:**
```bash
# バッチファイルで起動（ブラウザが自動で開きます）
tools\run_studio.bat

# または手動コマンド
python tools/server.py
```
- ブラウザアクセス: `http://localhost:8000`
