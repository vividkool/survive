# Vampire Survivor Game

## 概要
このプロジェクトは、Vampire Survivor風の見下ろし型2Dゲームです。プレイヤーは画面の中心に位置し、周囲から迫ってくる敵を避けながら生き残ることを目指します。

## ファイル構成
- `src/public/css/style.css`: ゲームのスタイルを定義するCSSファイルです。背景やキャラクターのスタイルが含まれています。
- `src/public/js/game.js`: ゲームのメインロジックを処理するJavaScriptファイルです。ゲームの初期化、ループ、描画処理が含まれています。
- `src/public/js/player.js`: プレイヤーキャラクター（円）の動きを管理するJavaScriptファイルです。プレイヤーの位置や移動に関する関数が含まれています。
- `src/public/js/enemy.js`: 敵キャラクター（ブロック）の動きを管理するJavaScriptファイルです。敵の生成や動きに関する関数が含まれています。
- `src/public/index.html`: ゲームのHTML構造を定義するファイルです。ゲーム画面のキャンバスやスクリプトの読み込みが含まれています。
- `src/app.js`: Expressアプリケーションのエントリーポイントです。サーバーの設定やルーティングが含まれています。
- `src/routes/index.js`: アプリケーションのルートを定義するファイルです。メインのルートハンドラーが含まれています。
- `package.json`: npmの設定ファイルで、プロジェクトの依存関係やスクリプトがリストされています。
- `.gitignore`: Gitで無視するファイルやディレクトリを指定するファイルです。

## セットアップ手順
1. リポジトリをクローンします。
   ```
   git clone <repository-url>
   ```
2. プロジェクトディレクトリに移動します。
   ```
   cd vampire-survivor-game
   ```
3. 依存関係をインストールします。
   ```
   npm install
   ```
4. サーバーを起動します。
   ```
   npm start
   ```
5. ブラウザで `http://localhost:3000` にアクセスしてゲームをプレイします。

## 注意事項
- このゲームは当たり判定がありませんので、敵に触れてもゲームオーバーにはなりません。
- ゲームのスタイルやロジックは今後のアップデートで改善される予定です。
